# Improvements backlog

One line per finding from the end-of-task tool-usage review: observed cost, the tool, the proposed
change, the expected saving. Shipped entries keep their measurement so a regression is visible.

| `dotnet format style`/`analyzers` had no equivalent, so every analyzer violation was fixed by hand through `replace_symbol_body` | `cleanup fix=style\|analyzers\|all` | apply the referenced analyzers' code fixes in-process, compile-gated, `UNFIXED <id>` for what no fixer covers | 1 call replaces `analyze` + N hand edits; asserted in `CodeFixServiceTests` |

| Formatting N touched files cost N calls, because `path=` took one file or the whole solution | `format`, `cleanup` | `path=` accepts a glob and a directory | N calls → 1 |
