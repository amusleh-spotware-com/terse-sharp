**Note on I84 — bytes are not tokens.** The 132 231 characters of leading indentation are ~3 % of
bytes but far less of the *token* count, because a tokenizer encodes a run of spaces in one or two
tokens while a `1234: ` gutter costs two or three per line. So the gutter change (I83) is worth more
than the raw byte figures suggest and the indentation change is worth less. Tab-compressing leading
indentation was considered and dropped: it would change the whitespace of any declaration an agent
copies back into `replace_symbol`, for a saving the tokenizer largely already makes.

## Tool-usage review — backlog-closure task

Measured over this task's own calls, per the continuous-improvement gate.

1. **Round trips.** `get_file_outline` → `get_symbol_source` → `replace_symbol` ran ~30 times. The
   outline already carries the line range, so a `get_symbol_source(symbolIds=[…])` batch on the members
   about to be edited would have folded ~10 calls — the batch shipped **in** this task (I72) but the
   installed server could not serve it (see 3). No new row.
2. **Payload.** `read_text` on `IMPROVEMENTS.md` answered **50.5 KB / persisted-to-disk** for a
   155-line range, because the rows are single lines of 1–3 KB each. `maxLines` bounds *lines*, not
   characters, so a file of very long lines has no usable bound. **New row: I94.**
3. **Fallbacks.** Two, both forced by the installed-vs-`HEAD` asymmetry: `edit_text force=true` to add
   `TerseErrorCode.Internal` (the `add_member`-on-an-enum fix was in the tree, not in the running
   0.20.0 binary) and the same for one duplicate-record removal in `FileTools.cs`. Not product
   defects — stated at the call, and both are closed by this release once installed.
4. **Failures.** Four `CompileRegression` rollbacks, every one the known callee-after-caller trap
   (`Tail`, `VerboseHelp`, `Document`, `Guarded`'s nullability) — not a tool defect. One
   `AmbiguousSymbol` on `Errors` (6 matches) and two `matches more than 100 symbols` refusals on
   `ToolBoundary.Run` / `MappedAnalyzers.Of`, each fixed by passing the documentation id the remedy
   named. The contract worked.
5. **Unanswerable.** `git status --porcelain` and `git diff --stat` at the end of the task: **I73**,
   already the largest open row.
